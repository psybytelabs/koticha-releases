# Koticha – Official Android Releases

Welcome to the official Android release repository for **Koticha**, developed by **PsyByte Labs**.

This repository hosts official Koticha APK releases. It is dedicated to distributing application builds and does not contain the website or application source code.

## Download Koticha

**[Download the latest Koticha release](https://github.com/psybytelabs/koticha-releases/releases/latest)**

You can also browse all available versions on the [Releases page](https://github.com/psybytelabs/koticha-releases/releases).

## Installation

1. Download the latest APK from the Releases page.
2. Open the downloaded APK on your Android device.
3. If Android asks for permission, allow installation from your browser or file manager.
4. Follow the installation instructions.

If you already have Koticha installed, install updates using the same official signing key.

## Release Information

Each release may include:

- Version name and version code
- Release notes and improvements
- Bug fixes
- APK download
- SHA-256 checksum for file verification

Check the release notes before installing an update.

## Authenticity and Security

Only download Koticha from the official PsyByte Labs release repository.

Do not install APK files from unofficial sources. Verify the SHA-256 checksum when one is provided.
